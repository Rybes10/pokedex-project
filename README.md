# Python Pokedex Project

A functional Pokedex application built with Python that retrieves real-time data from the PokeAPI. 

ALL CREDIT GOES TO CODE2COLLEGE FOR HELPING ME TO CHOOSE THIS PROJECT IN THE FIRST PLACE. 

## Features
- **Search by Name or ID:** Quickly find any Pokemon from the national pokedex.
- **Detailed Stats:** Displays types, height, weight, and base stats (HP, Attack, Defense, etc.).
- **Object-Oriented Design:** Built using custom `Pokemon` and `Pokedex` classes for clean data management.
- **Unit Testing:** Includes a test suite to ensure API reliability and data accuracy.

## Technology Stack
- **Language:** Python 3
- **APIs:** [PokeAPI](https://pokeapi.co/)
- **Libraries:** `requests` (for API calls), `unittest` (for testing)
